# 🚢 Titanic Dataset – Exploratory Data Analysis (EDA)

## 📌 Task 5 – Data Analyst Internship (Elevate Labs)

This project involves performing Exploratory Data Analysis (EDA) on the famous Titanic dataset using Python. The goal is to identify patterns, trends, and relationships in the data through statistical and visual analysis.

---

## 🧰 Tools Used

- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook / Google Colab

- Dataset Used: `Titanic-Dataset.csv`
- Source: [Kaggle Titanic Dataset](https://www.kaggle.com/c/titanic/data)

---

## 🔍 Objectives
- Understand the structure and summary statistics of the dataset.
- Handle missing values appropriately.
- Visualize the distribution of variables.

## 📊 Key Steps in the Analysis

1. **Data Inspection**
   - Used `.info()`, `.describe()`, `.value_counts()` to explore data.

2. **Data Cleaning**
   - Handled missing values in `Age` and `Embarked` using median and mode.

3. **Univariate Analysis**
   - Histograms and boxplots were used to study distribution and outliers.

4. **Bivariate and Multivariate Analysis**
   - Countplots and scatterplots analyzed relationships with `Survived`.
   - `sns.heatmap()` and `sns.pairplot()` used for correlation and pattern recognition.

5. **Visualization**
   - Explored survival rates by gender, class, age, fare, and embarkation port.

6. **Observations**
   - Females and 1st class passengers had higher survival rates.
   - Age and fare showed influence on survival.
   - Weak correlations among some features were noted.

7. **Summary**
   - Insights were documented after each plot.
   - Final findings were compiled to highlight key patterns and anomalies.
